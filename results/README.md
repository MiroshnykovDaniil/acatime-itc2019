# Results

The curated result files are imported. `results/summary.csv` is regenerated by
`make verify`; the paper's claims and their expected values are in
`results/claims.csv` and `docs/claims.md`.

```text
results/
  summary.csv
  tg-fal17/
    chained/                 # 6,889 (600 + 300 s)
    independent-600-a/       # 6,919
    independent-600-b/       # 6,930
    300s/r1..r5/             # 300 s runs; median 7,325
    best-300/                # 7,042
    exact-ablation/          # 7,220 / 7,053
  tg-spr18/
    certified/               # 22,180
    raw/                     # intermediate/infeasible files, not results
  lums-fal17/                # 1,602 seed/repair
  lums-spr18/                # 826 seed/repair
  negative/iku-fal17/        # 70 room collisions
```

Each run directory contains the runner output JSON, solution JSON, official
score JSON and (where emitted) solution XML. The official score is produced by
`src/scorer/score.py`; the internal GA estimate is not a reported result.

Verify everything:

```bash
make verify
```

The old 7,310 result and the initial 7,800 LNS seed are not yet imported; they
remain marked `planned` in `results/claims.csv`. They are not headline results.
Large raw logs and full run bundles should eventually go to the Zenodo release
rather than Git history.
