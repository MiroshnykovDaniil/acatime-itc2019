# Helper scripts

- `check_data.sh` — verify the SHA-256 checksums of the DTU reduced instances.
- Additional scripts will be added when the code and result files are imported:
  - `verify_results.sh` — recompute all reported scores;
  - `collect_results.py` — copy/rename curated runs from the internal workspace;
  - `smoke_test.sh` — quick end-to-end check on a small fixture.
